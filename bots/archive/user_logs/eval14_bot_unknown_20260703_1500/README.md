# eval14_bot_unknown_20260703_1500

과거 `eval14_user_log`를 표준 구조로 옮긴 중간평가 로그다. 원래 파일명은 상대 팀 이름 기반이었으므로 `manifest.tsv`에 원본 파일명과 팀명을 보존했다.

- `ranking.txt`: 순위/대전 목록 원본 텍스트.
- `summary.tsv`: 기존 `eval_summary.tsv`.
- `matches/`: `eval14_<번호>_<A|B>.txt` 형식으로 정규화한 대전 로그.
- `manifest.tsv`: 정규화 파일명, 원본 파일명, 팀명, 진영, 결과 매핑.
