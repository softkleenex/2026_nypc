# 2026-07-07 "알려진 맵도 서버로 검증 가능" 세션 요약

**대표 교체: 60.py → `bots/62.py`**

## 발견

- 대회는 제출 무제한 + 제출 즉시 8개 공식 샘플봇 로그를 돌려준다. 이걸
  활용하면 "알려진 8맵"도 로컬 리플레이가 아니라 **서버 실측**으로 범용
  로직을 검증할 수 있다 (사용자 제안: "제출해서 봇 로그 얻는건 무제한이야").
- `bots/61_test.py` = 60.py에서 `self.unknown_map`을 알려진 8맵에서도
  강제 True로 고정한 일회성 테스트. 이러면 `self.mp`가 `MAP_PROFILES`
  하드코딩 대신 `dict(chip=True)`로 완전히 덮어써져, **맵별 정답 암기 없이
  순수 범용 로직(관문게이트·견제부대·위협모델)만으로 승부**하게 된다.
- 서버 결과: **8전 8승 0패 0무** (60.py는 7승1무0패, 6번 맵이 만년 무승부
  였음). 로컬 재현 완전 일치(턴수까지 동일).

## 중요한 구분: 이게 유저 랭킹을 바꾸는가?

**아니다.** 랜덤맵(=유저 대결)에서는 60.py도 이미 `unknown_map=True`였다.
62.py가 바꾼 건 "알려진 8맵" 분기 하나뿐이라, 유저전 코드 경로는 60=62로
완전히 동일하다. 이번 발견의 의미는:

- 51~60에서 쌓아온 범용 로직(원래 유저전을 겨냥해 만든 것)이, 실제
  독립 코딩된 상대(공식봇 8종 — 수동/공격형/성장형/적응형 스펙트럼)에게도
  하드코딩 없이 확실히 통한다는 **로버스트니스 재확인**이지, 유저전에 새
  기능을 추가한 게 아니다.
- 실제 유저 랭킹에 51~60 개선이 반영됐는지는 여전히 **다음 유저 평가
  (7/8 10시 예정)**가 답할 질문 — 최근 평가(#19/20, 47 기준)는 이 개선들
  이전 세대라 아직 미확인.

## 검증 절차 (이중 감사)

1. 코드 감사: `diff bots/60.py bots/62.py` = 의도한 1줄뿐. `self.mp` 관련
   전 필드가 `.get(key, default)` 안전 접근이라 예외 위험 없음.
   `MAP_PROFILES`/`KNOWN_MAPS`는 안전하게 죽은 코드화. → **안전**.
2. 행동 정량 감사: econ/turtle 프록시 각 40게임×양쪽(640게임) + 샘플
   16게임, 총 656게임 시드 단위 전수 대조 — **60→62 전환으로 나빠진
   시드 0건**. 개선은 전부 `무승부→승리`(econ 3건, turtle 5건). WA 0,
   `max_ms` 완전 동일(16ms). → **승격 권장**.
