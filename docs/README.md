# NYPC Documentation Index

이 디렉터리는 루트 문서와 전략 기록을 NYPC 작업 흐름에 맞게 묶은 통합본을 제공한다. 원본은 삭제하거나 축약하지 않았다.

## 통합 문서

- `../AGENTS.md`: 현재 단일 작업 지침. 통합 전 `AGENTS.md`와 `CLAUDE.md` 원문을 포함한다.
- `workflow-strategy.md`: 통합 전 `docs/workflow.md`와 `strategy-plan.md`를 합친 개발 루프, 제출 전략, 실험 기록.
- `nypc-overview-rules.md`: `nypc_개요.txt`와 `game-rule.md`를 합친 대회 개요 및 NEXT NATION 룰북.
- `bots-organization.md`: `bots/` 제출 단위, 공식/유저 로그 의미, 보관 정책.
- `user-log-storage-review.md`: 현재 유저 로그 폴더 검토 결과와 앞으로의 저장 표준.
- `integration-check.md`: 원본 파일의 라인 수, 바이트 수, SHA-256, 통합본 포함 여부.

## 원본 문서

- `archive/agent-context.before-root-merge.md`: 루트 통합 전 작업 지침 통합본.
- `archive/AGENTS.before-agent-merge.md`: 통합 전 기여자 가이드 원본.
- `archive/CLAUDE.before-agent-merge.md`: 통합 전 프로젝트 컨텍스트 원본.
- `archive/workflow.before-workflow-merge.md`: 개발 워크플로우 원문.
- `archive/strategy-plan.before-workflow-merge.md`: 전략 계획과 제출 기록 원문.
- `../game-rule.md`: NEXT NATION 룰북 원문.
- `../nypc_개요.txt`: NYPC 대회 개요 원문.

## 사용 원칙

새로 읽을 때는 통합 문서를 먼저 보고, 특정 내용의 원문 위치가 필요하면 `integration-check.md`의 원본 경로와 해시를 확인한다. 로그 폴더와 `bots/archive/`는 삭제하지 않는다.
