# Documentation Guide

이 디렉터리는 공개 문서와 그래프를 보관한다. 대회 전체를 빠르게 이해하려면
루트 `README.md`와 `REPORT.md`를 먼저 읽는다.

| Path | Purpose |
| --- | --- |
| `../README.md` | 프로젝트 개요, 유저 평가 추이, 주요 봇 체크포인트 |
| `../REPORT.md` | 문제, 해결 과정, 실패 원인과 다음 대회 개선안 |
| `nypc-overview-rules.md` | 대회 안내와 NEXT NATION 공식 규칙 통합본 |
| `workflow-strategy.md` | 시간순 후보 실험, 검증 결과, 기각 사유 |
| `assets/` | README와 회고에서 사용하는 평가 그래프 |

새 문서는 특정 시점의 임시 분석보다 장기적으로 다시 읽을 목적이 있을 때만
추가한다. 서버·유저 로그 원문은 `docs/`로 복사하지 않고 `../bots/` 아래의
표준 로그 폴더에서 보존한다.
